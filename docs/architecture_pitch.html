Secure Agentic BI Gateway

Natural-language analytics that remains useful when requests are ambiguous, data is untrusted, and database permissions matter.

Input

User + role

Business question and authenticated role: Marketing, Analyst, or SecOps.

Planning + Reflection

BI Agent Orchestrator

Plans schema/tool use, interprets structured feedback, repairs a blocked plan or gives a safe refusal.

R3 memory

Approved Template Store

Retrieves safe query patterns only. Writes only after successful policy-approved execution; never stores raw table text.

MCP boundary + Guardrails

Security Gateway

Every tool call carries user role, request scope, timeout, and audit ID. It returns structured allow/block reasons to the agent.

Enforcement

Allow only registered tools, validate inputs, apply table/column policy, enforce limits, and log each decision.

Read-only MCP tool

get_schema

Returns only role-visible tables and columns, not the whole database schema.

Scoped read-only MCP tool

execute_sql

Parse AST; permit one SELECT; check table/column allowlist, row limit and timeout; use role-bound read-only DB view.

Extension

pandas_analytics

Consumes policy-checked result handles in an ephemeral, network-disabled container. Export requires confirmation.

Untrusted result boundary

Provenance and minimization

Text from tickets, feedback, and notes is labelled untrusted, bounded, and never treated as tool instructions.

Back to agent

Safe result summary or structured block reason informs reflection. The agent cannot obtain new permissions from retrieved text.

Why an agent, not a script?

The system must choose relevant schema and tools, recover from malformed or blocked actions, and explain safe partial answers for open-ended business requests.

Threat model v0

Assets: PII/salary confidentiality and database integrity.
Untrusted inputs: user prompts and text retrieved from tickets/feedback.
Core mitigation: permissions are enforced outside the LLM at the MCP gateway and DB connection.

Feasible MVP by W7

SQL gateway, 3 roles, 6--10 tables, policy tests and audit demo. Pandas sandbox and guarded export are extensions, not the critical path.

Project claim: a policy-enforced MCP gateway can preserve useful agentic BI while reducing unsafe data exposure and actions from over-privileged queries and untrusted table content.
